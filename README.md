# نظام إدارة ومتابعة أعمال الصيانة الدورية - قطاع أسيوط جنوب

تطبيق ويب متكامل لإدارة ومتابعة أعمال الصيانة الشهرية لهندسات قطاع أسيوط جنوب، مع لوحة تحكم احترافية، وإمكانية إدخال البيانات اليومية، رفع الوسائط، تقارير PDF، ومساعد ذكي.

## المميزات

- لوحة تحكم تعرض نسبة الإنجاز لكل هندسة شهرياً.
- إدخال سجلات الصيانة اليومية مع تفاصيل الأفراد والملاحظات.
- رفع صور وفيديو للأعمال.
- توليد تقارير PDF بتوقيعات المديرين.
- استيراد بيانات المستهدفات من ملف Excel.
- مساعد ذكي (يتطلب OpenAI API Key).
- دعم إضافة مكونات وهندسات جديدة.

## المتطلبات

- Python 3.8+
- Flask والمكتبات المذكورة في `requirements.txt`
- (اختياري) مفتاح OpenAI API للمساعد الذكي
